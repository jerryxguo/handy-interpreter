Handy Interpreter Support

Handy Interpreter translates spoken conversations, talks and announcements on iPhone. If you need help, try these steps:

  • Allow the microphone and speech recognition for Handy Interpreter in the Settings app, under Apps, Handy Interpreter.
  • Download both of your languages for translation in the Settings app, under Apps, Translate, Downloaded Languages.
  • If translations stop working for every language, restart the iPhone, then remove and download the languages again in the same place.
  • AI mode needs an internet connection. If it says it's busy, try again a little later.

AI mode preview

AI mode is a complimentary preview, free for a limited time. A future update may require a subscription. During the preview, everyone using AI mode shares a daily allowance, so if it has run out, AI mode works again the next day.
